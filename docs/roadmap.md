# Roadmap

This roadmap outlines the development goals and future plans for **EMON (Efficient Modular Object Notation)**.
It serves as a guide for contributors, researchers, and developers shaping the EMON ecosystem.

<br>

## 1. Project Vision

EMON aims to be a **compact**, **modular**, and **AI-friendly** structured data format focused on:

* Enabling efficient AI training with minimal token usage.
* Providing human-readable and modular schema definitions.
* Supporting cross-platform interoperability.

<br>

## 2. Current Version: 1.0

* Stable schema with explicit type definitions.
* Core tools: parser, converter, and test scripts.
* Includes training dataset with 1,000 EMON ↔ JSON examples.
* Documentation covers syntax, JSON comparison, and AI efficiency.

<br>

## 3. Short-Term Goals (Next 6 Months)

### Tooling Enhancements
    
* Add CLI support for parsing, validating, and converting EMON.
* Integrate EMON visualizer for GitHub Pages.

### Expanded Training Data

* Increase dataset diversity: more nested objects, arrays, AI prompts, and configuration data.
* Add multilingual datasets for AI model training.

### Documentation Improvements
* Interactive examples using GitHub Pages.
* Tutorials for researchers and developers.

<br>

## 4. Mid-Term Goals (12–18 Months)
* Release **EMON v1.1** with extended type support.
* Create standardized test suites for multi-language parser validation.
* Add integration examples with AI pipelines, LLMs, and data research tools.

<br>

## 5. Long-Term Goals (18-24 Months)
* Build a community-driven schema and contribution process.
* Publish EMON as a formal research reference or whitepaper.
* Develop EMON ecosystem tools - IDE plugins, browser extensions, and AI model integrations.

<br>

## 6. Contribution Guidelines
* Use consistent type definitions across new examples.
* Submit PRs for bug fixes, schema enhancements, or additional training data.
* Follow semantic versioning and maintain backward compatibility.

<br>

## 7. Summary

The EMON roadmap supports steady growth, practical adoption, and AI research integration.
It aims to bridge efficiency, readability, and modularity across tools and data systems.

<br>

## Notes

* Prioritize AI readability while keeping syntax simple for humans.
* Maintain backward compatibility with previous schema versions.
* Encourage consistent structure and naming for clarity and reusability.
