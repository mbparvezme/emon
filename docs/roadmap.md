# Roadmap

This roadmap outlines the development goals and future plans for EMON (Efficient Modular Object Notation). It serves as a guide for contributors, researchers, and users of the EMON ecosystem.

<br>

## 1. Project Vision

EMON aims to be a compact, modular, and AI-friendly structured data format. Its primary goal is to:

* Enable efficient AI training with minimal token usage.
* Provide human-readable, consistent, and modular schema definitions.
* Facilitate cross-platform usage and interoperability.

<br>

## 2. Current Version: 1.0

* Stable schema with core types and explicit typing.
* Tools included: parser, converter, and basic test scripts.
* Training dataset prepared with 1,000 EMON↔JSON examples.
* Documentation for syntax, comparison with JSON, and AI efficiency.

<br>

## 3. Short-Term Goals (Next 6 Months)

### Tooling Enhancements
    
* Add CLI support for parsing, validating, and converting EMON.
* Integrate EMON visualizer for GitHub Pages.

### Expanded Training Data

* Increase dataset diversity: more nested objects, arrays, AI prompts, and configuration data.
* Introduce multilingual examples for AI training.

### Documentation Improvements
* Interactive examples using GitHub Pages.
* Tutorials for researchers and developers.

<br>

## 4. Mid-Term Goals (6–12 Months)
* Version 1.1 of EMON schema with extended type support.
* Standardized test suite for EMON parsers across platforms.
* Integration examples with AI pipelines, LLMs, and research datasets.

<br>

## 5. Long-Term Goals (12–24 Months)
* Community-driven schema evolution and contributions.
* Publication of EMON as a formal research reference.
* EMON ecosystem tools: IDE plugin, browser extensions, and AI model support.

<br>

## 6. Contribution Guidelines
* Use consistent type definitions across new examples.
* Submit PRs for bug fixes, schema enhancements, or additional training data.
* Follow semantic versioning and maintain backward compatibility.

<br>

## 7. Summary

The EMON roadmap ensures incremental growth, AI efficiency, and research adoption. It is designed to support practical applications, research datasets, and open-source contributions.

<br>

## Notes

* Prioritize AI readability while keeping files human-friendly.
* Maintain backward compatibility for all released features.
* Encourage best practices for data consistency and clarity.
