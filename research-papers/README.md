# EMON Research Project

## Overview
EMON (Efficient Minimal Object Notation) is a compact, human-readable alternative to JSON designed to reduce token usage in AI applications. This repository includes:

- Research paper (`main-paper.pdf`, `main-paper.tex`)
- Code and tools for parsing and converting EMON (JS, PHP, Python)
- Results, benchmarks, and token usage analysis
- Abstract and Appendices for EMON syntax and examples

## How to Use
1. Read the Main Paper for methodology and design.
2. Use Code_and_Tools to convert JSON to EMON and vice versa.
3. Check Results for efficiency benchmarks.
4. Refer to Appendices for syntax, examples, and training datasets.
